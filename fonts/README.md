# Font files for Figma parity

Put the source font files in this folder using exact names:

- `HalvarBreitschrift-Light.woff2`
- `HalvarBreitschrift-Regular.woff2`
- `HalvarBreitschrift-Medium.woff2`
- `HalvarBreitschrift-Bold.woff2`
- `ProximaNova-Regular.woff2`

After adding these files, the page will render with the same font families used in Figma:
- Halvar Breitschrift
- Proxima Nova
- Manrope (loaded from Google Fonts)
